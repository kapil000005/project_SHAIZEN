convention used in project

struct : snake_case.
  prefixed by SS_ : SHAIZEN_STRUCT
  SS_<struct_name>_t
variable : snake_case
  prefixed by NONE
  <variable_name>
function to be provided by SHAIZEN.
  prefix by SF_ : SHAIZEN_FUNCTION
  SF_<function_name>
constants provided by SHAIZEN : UPPER_CASE
  prefixed by SC_ : SHAIZEN_CONSTANT
  SC_<CONSTANT_NAME>
